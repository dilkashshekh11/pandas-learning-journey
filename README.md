# 📊 Pandas Series Learning Journey

A hands-on learning repository focused on **Pandas Series** in Python, featuring code examples, practice exercises, and notes on data creation, indexing, filtering, string manipulation, type conversion, missing data handling, statistical analysis, and data transformation.

As a BSc (Hons) Computer Science with AI student, I am strengthening my Python and data analysis skills to build a solid foundation for Artificial Intelligence**.

## 🎯 Learning Objectives

- Understand Pandas Series and its core properties.
- Learn efficient data access, indexing, and slicing.
- Perform filtering and conditional selection.
- Clean and manipulate string data.
- Convert and manage data types.
- Handle missing values effectively.
- Perform statistical analysis and categorical aggregation.
- Apply custom functions and conditional transformations.
- Sort data and manage indexes.

## 📚 Topics Covered

### 1. Series Fundamentals and Properties
- Creating Series from lists, dictionaries, and NumPy arrays.
- Understanding `index`, `values`, `dtype`, `shape`, and `size`.
- Working with custom indexes and Series names.

### 2. Indexing, Slicing, and Data Access
- Accessing individual elements and data ranges.
- Selecting values by labels and positions.
- Using `.loc[]` and `.iloc[]`.

### 3. Filtering and Conditional Selection
- Boolean indexing and masking.
- Applying comparison operators.
- Combining multiple conditions.

### 4. String Manipulation
- Using `.str` methods for text processing.
- Changing letter cases and removing whitespace.
- Searching and replacing string values.

### 5. Type Conversion
- Converting data types using `astype()`.
- Understanding Series data types.
- Maintaining consistent data formats.

### 6. Missing Data Handling
- Identifying missing values using `isna()` and `isnull()`.
- Removing missing values with `dropna()`.
- Filling missing values using `fillna()`.
- Understanding the effect of missing data on analysis.

### 7. Statistical Analysis and Aggregation
- Calculating `sum()`, `mean()`, `median()`, `min()`, and `max()`.
- Measuring variability using `std()`.
- Finding distinct values with `unique()`.
- Analyzing category frequencies using `value_counts()`.

### 8. Custom Functions and Data Transformation
- Applying functions using `apply()`.
- Performing element-wise transformations.
- Replacing values conditionally using `where()`.

### 9. Index Management and Sorting
- Sorting values with `sort_values()`.
- Sorting index labels with `sort_index()`.
- Resetting indexes using `reset_index()`.
